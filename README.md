# Лабораторна робота №3 — обробка помилок і структура Python-пакета

Проєкт демонструє типізовану обробку винятків, контекстні менеджери, власну ієрархію помилок, ланцюжки raise from, повторне піднесення винятку та документований пакет.

## Запуск

Потрібен Python 3.10 або новіший. Із кореня репозиторію виконайте:

```console
python -m resilient_app
```

Зовнішні залежності не потрібні; використовується стандартна бібліотека Python.

## Структура

```text
resilient_app/
├── __init__.py        # публічний API та __all__
├── __main__.py         # запуск через python -m
├── cli.py              # консольна демонстрація
├── errors/             # класи доменних помилок
└── services/           # обробка записів і журналювання
```

У репозиторії також є PDF-звіт, запис виводу та зображення результатів запуску.
